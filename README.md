# 🚀 Anish Raj Portfolio

A modern full-stack portfolio built to showcase my projects, skills, and development journey.

## 🌐 Live Demo

https://portfolio-three-lilac-81.vercel.app/

## ✨ Features

* Modern responsive UI
* Smooth animations with Framer Motion
* Dynamic project showcase
* GitHub-integrated project management
* Contact form with backend API
* MongoDB-powered message storage
* Mobile-friendly design
* Fast deployment with Vercel & Render

## 🛠️ Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Framer Motion
* Axios

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

### Deployment

* Vercel
* Render

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/CodeWizard-Anish/Portfolio.git
cd Portfolio
```

### Frontend Setup

```bash
cd client
npm install
npm start
```

### Backend Setup

```bash
cd server
npm install
npm run dev
```

### Environment Variables

Create a `.env` file inside the server directory:

```env
MONGO_URI=your_mongodb_connection_string
```
